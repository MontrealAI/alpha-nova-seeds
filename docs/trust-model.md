# Trust Model (v2.6 RC)

Nova-Seeds v2.6 RC prioritizes proof over rhetoric.

## Trust anchors
- On-chain event log from registry/governance contracts.
- Threshold attestation payloads validated against canonical schemas.
- Release provenance artifacts (hashes + attestations + SBOM).

## Operator trust boundaries
- Smart contracts define identity/proof/settlement/governance state transitions.
- Backend indexer is a derived read model and must remain deterministic.
- Dashboard is an operator convenience surface, not a source of truth.

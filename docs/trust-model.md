# Trust Model (v2.6 RC)

Nova-Seeds v2.6 RC focuses on proof surfaces, not final trust minimization claims.

## Trust assumptions
- Contract owners/admins manage privileged configuration.
- Threshold attestation signer trust is maintained by governance process.
- Backend indexer truth derives from canonical chain events and finalized block windows.

## Boundaries
- Identity and proof are on-chain anchored.
- Read models and dashboard are operational views, not settlement authority.

## Operator guidance
Treat this release as verifiable candidate infrastructure pending audit and broader adversarial testing.

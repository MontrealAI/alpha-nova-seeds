# Public Proof Docket Template

This folder is a starter shell for public proof publication.

## Contents
- `manifest.json`: top-level docket manifest.
- `artifacts.json`: hashes and pointers to binaries/docs.
- `claims.json`: constrained claims and known non-goals.

## Usage
1. Fill commit SHA and release tag.
2. Add artifact hashes from `SHA256SUMS`.
3. Add links to attestations and SBOM.
4. Keep claims strictly testable.

# Proof Docket Template (v2.6 RC)

Use this folder as a starter shell for publishing public proof artifacts.

## Included starter manifest files
- `proof-docket.manifest.json`
- `artifact-index.json`
- `governance-decision-log.json`
- `attestation-index.json`

## Minimum publication package
1. Release tag and commit SHA.
2. SHA256SUMS file.
3. Attestation references.
4. Seed/governance proof references.

# Support

## Operator support channels
- GitHub Issues for bug reports and feature requests.
- GitHub Discussions for design and operations questions.

## What to include in support requests
- component area,
- exact commit/tag,
- logs or error output,
- reproduction steps,
- expected outcome.

## Release candidate disclaimer
Support responses for v2.6 are for a **verifiable release candidate** track and may include migration/recovery instructions as the release hardens.

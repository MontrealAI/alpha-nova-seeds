# Security Policy

## Scope
This repository currently publishes release candidates and foundational architecture. It does **not** assert a completed audit.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Security Advisories.

If that channel is unavailable, open a private report with:
- affected component (`contracts`, `backend`, `sdk`, `dashboard`),
- impact summary,
- proof-of-concept steps,
- suggested mitigation.

## Disclosure expectations

- We acknowledge reports within 3 business days.
- We provide a triage status update within 7 business days.
- We coordinate disclosure after a fix plan exists.

## Safe harbor

Good-faith testing against your own resources is welcome. Do not disrupt public infrastructure or exfiltrate private data.
